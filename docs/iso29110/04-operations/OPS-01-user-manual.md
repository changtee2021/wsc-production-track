ชื่อบทบาทด้านล่างเป็นบทบาทในซอฟต์แวร์ ไม่ใช่ชื่อตำแหน่งในบริษัท

## พนักงานสแกน

1. เปิดหน้า `/scan`
2. ระบุงาน พนักงาน ขั้น และหมวด แล้วเลือกเริ่มหรือจบ
3. ผลที่โค้ดทำเมื่อข้อมูลผ่าน: มีแถวใน `production_logs`
4. ถ้าพนักงานหรือขั้นถูกปิด ระบบไม่บันทึกและส่งข้อความผิดพลาด

ขั้นตอนกดบนจอทีละปุ่มเป็น NOT VERIFIED เพราะรอบนี้ไม่ได้เดินหน้าจอจนครบ

## พนักงาน QC

1. เปิดหน้า `/qc` แล้วเข้าด้วยวิธีของแผนก QC
2. เลือกงานและหมวด
3. เลือกผ่านหรือไม่ผ่านทุกรายการ ข้อที่ไม่ผ่านต้องมีหมายเหตุ
4. แนบรูปหรือวิดีโอในหลักฐานรวมอย่างน้อยหนึ่งรายการแล้วส่ง
5. ผลที่โค้ดทำ: มีแถวใน `qc_reports` และรายการใน `qc_report_items`

## พนักงานแพ็ค

ทำแบบเดียวกับ QC ที่หน้า `/packing` ผลอยู่ที่ `packing_reports`

## แอดมิน

1. เปิด `/admin` แล้วเข้าสู่ระบบ
2. ใช้เมนูใน `AdminSidebar.tsx` เพื่อเปิดรายงานและตั้งค่า
3. ออกจากระบบที่ปุ่ม Logout ของโครงหลังบ้าน

รหัสเข้าใช้ไม่เขียนในคู่มือนี้
