ใช้ข้อมูลตัวอย่างที่แยกจากงานผลิตจริง เอกสารนี้ไม่บอกให้ทดลองเขียนลงฐานที่โรงงานใช้งานอยู่

## ลำดับสาธิต

1. เปิดภาพรวมจาก DISC-01 และแผนภาพใน SI-02
2. เปิด `/admin` แสดงว่าไม่มีโทเคนแล้วเข้ากลุ่มหน้าที่ป้องกันไม่ได้ จากนั้นเข้าด้วยบัญชีสาธิต
3. แสดงเมนูตามกลุ่มใน `AdminSidebar.tsx` อย่างน้อย Dashboard, คิวผลิต, รายงาน QC, รายงานแพ็ค
4. ถ้ามีข้อมูลตัวอย่าง ให้เดิน `/scan` หนึ่งขั้น แล้วชี้แถวที่เกิดจากตัวอย่างนั้น
5. เดิน `/qc` และ `/packing` จนส่งรายงานตัวอย่างหนึ่งใบ ชี้กฎหมายเหตุและสื่อรวม
6. เปิดหน้ารายงานที่ `/qc-reports` และ `/packing-reports`
7. แสดงข้อความผิดพลาดเมื่อไม่กรอกหมายเหตุของข้อที่ไม่ผ่าน
8. เปิดผล `npm test` จาก QA-03
9. เปิด `git log` ช่วงที่มี pull request ของงานสแกนทดลอง
10. ชี้เอกสารใน `docs/iso29110/README.md` และช่อง PENDING ใน PM-08
